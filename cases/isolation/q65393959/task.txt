through containerd's CRI (containerd namespace "k8s.io"). The container

bench65393959-owner, bench65393959-other). The file /data/state, and so the

"bench65393959-owner". The image's program /usr/bin/rotate is a script of the

(a docker user would run `docker exec -u ...` here; crictl exec has no such
option, and su and sudo do not exist in the image).

"bench65393959-app", as the user "bench65393959-owner", so that it completes
and writes /data/done.
