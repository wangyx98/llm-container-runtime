A MicroK8s-style node runs containerd as its container runtime, on its own socket: /run/bench66754136/containerd/containerd.sock (not the default one). There is no Docker on it. Its images (the ones the kubelet uses) are in the containerd namespace k8s.io; the namespace default holds a few others, and refs that look alike are in both. "ctr images list" takes optional filters after its options ("ctr images list [command options] [flags] [<filter>, ...]"), but its help does not say how to write one. Someone wants to list only the images whose ref contains some text, for example kafka, without grep, for any text they give.

Create the bash script /tmp/bench66754136/ref-filter.sh (it is run with bash) that takes two arguments, a text and the path of an output file, and writes into the file ONE line: a ctr filter (the single string that is given to ctr as one filter argument) such that "ctr -a /run/bench66754136/containerd/containerd.sock -n k8s.io images list -q FILTER" lists exactly the images of the namespace k8s.io whose ref contains the text, written exactly as given (the text is plain text: a character in it that means something in a regular expression, a dot for example, is only that character, and it can have slashes, colons, dots and dashes), and nothing else: no image whose ref does not contain it, none that does contain it left out. The lab runs ctr itself with your line as one argument, so what is wanted is the filter, not a command line and not shell quoting. The script only reads: it must not pull, import, tag, remove or prune any image, nor change a namespace or restart containerd. It will be run again later, for other texts, after images have been added to the node, so it cannot hold a list of today's refs. After creating it, run it for the text kafka with the output file /tmp/bench66754136/filter.txt.

Allowed: the standard shell tools, python3, sudo and ctr. Do not use Docker or nerdctl.

The current user has passwordless sudo. Unless stated otherwise, assume container-runtime commands need sudo.

Return the commands needed to complete the task.
